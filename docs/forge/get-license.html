Ta clé Forge est sur itch.io

Après ton achat, tu peux récupérer ta clé directement sur la page de téléchargement de Forge.

  1. Ouvre le lien de téléchargement reçu d’itch.io après l’achat.
  2. Clique sur Request key (récupérer la clé) dans la section des clés externes, puis copie ta clé Forge.
  3. Télécharge la dernière version de Forge sur cette même page.
  4. Dans Forge, colle la clé dans « Créer mon compte », puis choisis ton email et ton mot de passe.

Déjà inscrit ? Choisis « Se connecter » dans Forge. La clé reste associée à ton compte.
