# Sécurité

Ne publie pas de vulnérabilité, de jeton ou de donnée utilisateur dans une issue GitHub.

En cas de découverte sensible :

1. arrête les tests qui pourraient exposer davantage de données ;
2. conserve uniquement les informations nécessaires pour reproduire le problème ;
3. contacte directement le propriétaire `@forgestudioapp` sur GitHub ;
4. attends son accord avant toute divulgation publique.

Les fichiers de session, licences, clés d'API, mots de passe et fichiers `.env` ne doivent jamais être commités.
