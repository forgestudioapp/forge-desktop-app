Politique de confidentialité

Dernière mise à jour : 30 août 2026

1. Collecte des données

Forge Desktop collecte les données suivantes :

  • Token d'authentification Roblox (OAuth 2.0) — utilisé uniquement pour accéder à l'API Roblox et interagir avec tes expériences.
  • Clés API tierces (ex : Tripo3D, OpenAI) — fournies par l'utilisateur et stockées uniquement en local sur ta machine.
  • Chemins de fichiers locaux — pour accéder à tes projets Roblox sur ton ordinateur.
  • Préférences utilisateur (thème, langue, paramètres) — stockées en local.

2. Utilisation des données

Les données collectées sont utilisées exclusivement pour :

  • Fonctionnalités de l'application (conversion d'assets, édition de scripts, connexion à Roblox Studio).
  • Amélioration de l'expérience utilisateur.

3. Partage des données

Nous ne vendons, ne partageons et ne transmettons jamais tes données à des tiers. Tes clés API et tokens restent sur ta machine et ne quittent jamais ton ordinateur, sauf lors des appels directs aux services concernés (Roblox, Tripo3D, etc.).

4. Sécurité

Toutes les données sensibles (tokens, clés API) sont stockées localement sur ton appareil. Aucune donnée n'est envoyée à nos serveurs — l'application fonctionne entièrement en local.

5. Cookies

Forge Desktop n'utilise pas de cookies. L'application est un logiciel de bureau et n'implémente aucun跟踪 ou analytics.

6. Droits utilisateurs

Tu peux à tout moment :

  • Révoquer l'accès OAuth via les paramètres de ton compte Roblox.
  • Supprimer tes clés API depuis les paramètres de l'application.
  • Désinstaller l'application pour supprimer toutes les données locales.

7. Modifications

Cette politique peut être mise à jour. Les changements seront publiés sur cette page avec une date de mise à jour révisée.

8. Contact

Pour toute question concernant cette politique de confidentialité, contacte-nous via le GitHub du projet.
